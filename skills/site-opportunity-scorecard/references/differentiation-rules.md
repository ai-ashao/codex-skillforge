# Differentiation Rules

Different codebases are not required. Different user value is required.

## Classification

### NONE

The candidate completes the same job for the same user with the same workflow and output. The new site has no independent reason to exist.

Examples:

- identical converter under a new domain;
- same game guide pages with rewritten copy;
- same calculator with only a different color theme.

### COSMETIC

The candidate changes presentation but not product value.

Examples:

- new logo, color palette, domain, or H1;
- different order of feature cards;
- “fast,” “free,” and “easy” claims shared by all competitors;
- a homepage that promotes a different existing feature while all pages remain identical.

Cosmetic differentiation cannot justify an independent site by itself.

### MODERATE

The candidate serves a clearer segment or scenario and changes some product behavior.

Examples:

- same conversion engine, but different defaults, output presets, onboarding, examples, and content for academic users;
- a general image tool specialized for marketplace listing requirements;
- a general game database specialized for compatibility tracking.

Moderate differentiation often supports an existing-site section first.

### STRONG

The candidate has a distinct job-to-be-done, product path, output, content system, and distribution reason.

Examples:

- Markdown conversion suite versus a social-image creation product whose primary output is shareable branded images;
- generic workshop downloader versus a game-specific mod compatibility tracker with release/version data;
- general passport-photo maker versus a country-specific compliance workflow with distinct rules and guidance.

Strong differentiation can justify a separate site when search opportunity and risk scores also support it.

## Independent brand test

The candidate has an independent brand reason only when a target user can answer:

- Why use this instead of the host site?
- Why remember this name?
- Why recommend or link to it?
- What specific result does it deliver better?

A clever name or exact-match domain is not an independent brand reason.
